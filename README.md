# Enterprise GRC Framework & ISO 27001 Gap Analysis: Public Sector Compliance

## 📌 Project Overview
This repository contains a comprehensive Governance, Risk, and Compliance (GRC) framework designed to qualify an innovative SaaS digital communication platform (**Loopeli**, targeting elderly care) for Swedish municipal procurement (*offentlig upphandling*). 

The project bridges technical execution with legal and strategic security requirements, ensuring compliance with **GDPR**, the **EU NIS2 Directive**, and **ISO/IEC 27001:2022** standards.

---

## 📂 Repository Contents

### 1. External Analysis (`External Analysis.xlsx`)
A full environmental scanning matrix focusing on public sector prerequisites:
* **Stakeholder Mapping:** Analyzes requirements for Municipal Procurement Officers, Data Protection Officers (DPOs), and Digital Inspectors.
* **Legal Frameworks:** Details impact assessments for GDPR Article 28 (DPA), Articles 44–46 (Third-country data transfers regarding US-based cloud infrastructure), and Article 35 (DPIA).
* **Macro Trends:** Addresses the strategic shift required by the **NIS2 Directive** onboarding tighter supply chain security mandates for public entities.

### 2. ISO 27001 Gap Analysis (`Gap-Analysis .xlsx`)
A rigorous compliance audit against the **ISO/IEC 27001:2022** framework to identify organizational and technical vulnerabilities:
* **Critical Findings (Level 4 - Serious Gaps):** Evaluated severe gaps in *Information Security Policies (5.1)*, *Access Control (5.15)*, *Cloud Services Security (5.23)*, and *Use of Encryption (8.24)* due to non-EU data hosting risks.
* **Established Baselines:** Validated solid existing controls for *Asset Inventories (5.9)* and *Information Deletion (8.10)*.
* **Remediation Mapping:** Connects technical deficiencies directly to strategic business motivations, providing a roadmap to achieve procurable status.

## 🛠️ Key Competencies Demonstrated

* **Regulatory Translation:** Ability to convert complex EU directives (GDPR, NIS2) into actionable IT architecture requirements.

* **Stakeholder Communication:** Experience structuring documentation tailored to governance boards, legal advisors, and municipal auditors.
